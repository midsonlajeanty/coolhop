# Security policy

coolhop runs with full access to the Coolify database, so security reports matter.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting instead: **Security → Report a vulnerability** on this repository.

Include the coolhop version, the Coolify version and the steps to reproduce. Never attach a database dump or real credentials.

You will get an answer within a few days.

## Supported versions

Only the latest release receives fixes.
